# 仓库开放文档台账来源格式

文件为 ODS ZIP，读取 content.xml。支持 table-row、table-cell、covered-table-cell、行列重复、列跨度（table:number-columns-spanned），值类型 string、float、boolean、date、time；text:p 中 text:s 的重复空格与 text:line-break 保留。行跨度（table:number-rows-spanned）不在承诺范围内：登记矩形并在 issues 标记 unsupported-feature，不假装完整。公式只接收 office 缓存值并标记 cached/missing，不求值。tables 参数指定工作表和逻辑闭合矩形，region 顺序为 [minColumn,minRow,maxColumn,maxRow]（单个矩形；省略 region 表示整张表）；默认只返回有语义内容的单元格，重复空白不生成记录，未给 region 时也不统计空白尾部。坐标从1起，覆盖格引用合并原点但不复制值。行列重复只做坐标算术，不把重复次数展开到内存。XML 禁止 DOCTYPE、ENTITY 与 CDATA，外部实体一律拒绝。

`fixtures/scenarios.json` 给出本机来源入口和允许读取的资源；`GET /manifest` 返回同样的来源描述。`GET /trace` 返回当前进程内真实来源访问记录。资源接口为 `GET /files/百分号编码的资源名`，支持单段 Range、ETag 和 If-Match；资源名必须出现在来源清单中。数据不是新闻原文，不连接真实客户或设备。

格式参考：https://docs.oasis-open.org/office/OpenDocument/v1.3/os/part3-schema/OpenDocument-v1.3-os-part3-schema.html。本项目只承诺上文列出的范围；未列出扩展应保留原文并明确不支持，不能假装完整解析。
